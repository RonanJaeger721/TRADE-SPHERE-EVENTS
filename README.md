# Trade Sphere Events

Milestone 1 foundation preview. All listings are demonstration content. No credentials, payments, reservations or ticket issuing are accepted.

## Run locally

`npm install`
`npm run dev`
Open http://localhost:3000

## Validate

`npm run typecheck`
`npm run build`
`git diff --check`

## Routes

Homepage, event directory and four event details, categories, search, organiser information, about, contact, FAQs, advertising and draft policy information. Future application routes return honest milestone status views. Unknown pages return 404.

See docs/ARCHITECTURE.md and PROJECT_PROGRESS.md for next stages and release evidence. The SQL is a draft and has not been applied to a database. Keep demo search engines disabled until a real content launch.
